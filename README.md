# 基于 NapCat 的 QQ 群重复成员检查工具

> **简介**：基于 [NapCat](https://github.com/NapNeko/NapCatQQ) 的 Windows 开源脚本，目前提供以下功能：

## 功能

1. **全群扫描**——以 A 群为基准，查找 A 群成员还出现在哪些其它群（主要用于识别跨群熟人）；
2. **QQ 号反查**——查询指定 QQ 出现在哪些群；
3. **出现群数排行**——查看成员加入群聊数量的排行。

以上三项均只能查询**本账号已加入的正常群聊**，被封禁或未加入的群聊无法查询。

## 开发背景

最初想在 GitHub 上寻找现成的 Q 群成员查重工具，未找到合适的，于是自己写了一个。

相关查询功能依靠 GitHub 上的 [NapCat](https://github.com/NapNeko/NapCatQQ) 项目，只需下载编译好的文件解压即可，**仅作为启动依赖，无需改动任何 NapCat 的源文件**。

## NapCat 版本选择

推荐使用 **NapCat.Shell** 或 **NapCat.Shell.Windows.Node** 两个版本，其他版本请参考 NapCat 的使用教程配置。

- 本地电脑**已有 Node 环境**：下载 `NapCat.Shell`；
- **不确定是否有环境**：下载 Node 版（`NapCat.Shell.Windows.Node`，自带 Node 环境）。

## 使用教程

### 一、启动 NapCat

1. 进入下载解压好的 NapCat 文件夹，双击 `launcher.bat` 启动服务；
2. 启动成功后，服务会自动扫描本地已登录过的账号；
3. 在命令行窗口中**按住 Ctrl 点击本地服务器链接**，会自动填入 Token；
   （Token 会在当前窗口显示，也可在本地 `napcat\config\webui.json` 中查看。）
4. 点击链接打开本地服务页面，快捷登录选择要查询的账号；
5. 登录完成后，进入本地服务器后台。

### 二、配置网络

1. 在左侧「新建」中进入**网络配置**；
2. 选择「HTTP 服务器」，按以下参数填写：

   | 配置项 | 值 |
   | --- | --- |
   | 名称 | 任意填写 |
   | 端口 | `3000` |
   | 启用 CORS | 是 |
   | 消息格式 | `Array` |
   | Token | `dupcheck-7f3a` |

3. 若 3000 端口被占用，可用记事本打开脚本，将访问端口改为空闲端口。

完成以上配置后，脚本即可正常使用。

### 三、运行脚本

由于脚本基于 Windows 自带的 PowerShell 编写，需使用 PowerShell 运行：
右键 `.ps1` 文件 →「使用 PowerShell 运行」，然后按提示输入对应数字。

如果 PowerShell 无法运行，也可以使用 `bat` 启动。

查询结束后会自动导出 CSV / TXT 名单。
